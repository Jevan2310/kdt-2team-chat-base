# 소켓 이벤트

- 연결: `io({ auth: { token } })` — 서버가 토큰을 확인하고, 실패하면 `connect_error` (`unauthorized`)
- 이름 규칙: `대상:동작` (예: `room:created`)

## 서버 → 화면

| 이벤트 | 언제 | 받는 사람 | 데이터 |
|---|---|---|---|
| `server:hello` | 연결 직후 | 연결한 사람 | `{ message, socketId }` |
| `room:created` | 누가 방을 만들었을 때 | 접속한 모두 | `{ id, name, type, createdBy, createdAt, memberCount }` |
| `room:members` | 누가 방에 처음 들어오거나 나갔을 때 | 접속한 모두 | `{ roomId, change: 'join' \| 'leave', user }` |
| `message:new` | 새 메시지가 저장됐을 때 (보낸 사람 포함) | 그 방 화면을 연 사람 (`room:N` 그룹) | message ([모양](REST-API.md#message-모양)) |
| `message:updated` | 메시지가 수정·삭제됐거나 반응이 바뀌었을 때 | 그 방 화면을 연 사람 | 바뀐 message 전체 → 화면은 같은 id를 새것으로 교체 |
| `read:update` | 누가 책갈피를 옮겼을 때 (읽음, 보내기) | 그 방 화면을 연 사람 | `{ roomId, userId, lastReadMessageId }` → 메시지 옆 숫자 다시 계산 |
| `room:read` | 내가 그 방을 읽었을 때 | 내 모든 탭 (`user:N`) | `{ roomId, lastReadMessageId }` → 그 방 안 읽은 개수 0 |
| `notify:message` | 새 메시지 (보낸 사람 제외) | 그 방 참여자 모두 (`user:N`, 방 화면을 안 열어도) | `{ roomId, roomName, message }` → 안 읽은 개수 +1, 알림 토스트 |

## 화면 → 서버

`ack` = emit 마지막 인자로 넘기는 콜백. 서버가 처리 결과를 그 사람에게만 돌려준다.

| 이벤트 | 언제 | 보내는 값 | ack 로 받는 값 |
|---|---|---|---|
| `room:join` | 방 화면을 열 때, 재연결됐을 때 | `{ roomId }` | `{ ok }` 또는 `{ ok: false, message }` (참여 안 한 방) |
| `room:leave` | 방 화면을 닫을 때 (참여는 유지) | `{ roomId }` | — |
| `message:send` | 메시지 보낼 때 | `{ roomId, content }` (1~2000자) | `{ ok, message }` 또는 `{ ok: false, message: '오류 설명' }` |
| `message:edit` | 내 글 수정 | `{ messageId, content }` (1~2000자) | `{ ok, message }` 또는 `{ ok: false, message }` (남의 글·지운 글·시스템 메시지는 거절) |
| `message:delete` | 내 글 삭제 | `{ messageId }` | `{ ok, message }` (내용이 비고 `deletedAt`이 채워짐) |
| `reaction:toggle` | 반응 누르기/취소 (참여자 누구나) | `{ messageId, emoji }` (6개 중 하나) | `{ ok, message }` |
| `message:read` | 방 화면이 보이는 동안 마지막 메시지가 바뀔 때, 탭이 다시 보일 때 | `{ roomId, messageId }` | — (책갈피는 앞으로만 이동, 그 방 메시지일 때만) |

## 소켓 그룹 (서버 안)

| 그룹 | 들어가는 소켓 | 쓰는 곳 |
|---|---|---|
| `room:<방 id>` | 그 방 화면을 연 소켓 | `message:new` 보내기 |
| `user:<사용자 id>` | 그 사람의 모든 소켓 (탭 여러 개) | 방에서 나가면 그 사람 소켓을 한꺼번에 `room:N`에서 빼기 |

## 화면 흐름

```text
방 화면 열기: POST /api/rooms/:id/join → emit room:join → GET 방 정보 + GET 메시지
보내기:       emit message:send → 서버 저장 → io.to(room:N).emit message:new → 모두 화면에 추가
읽음:         메시지 표시 + 탭 보임 → emit message:read → 서버 책갈피 이동 → read:update(방) + room:read(내 탭들)
알림:         다른 방에 새 메시지 → notify:message → 배지 +1, 토스트 (그 방을 보고 있으면 무시)
수정·삭제·반응: emit message:edit / message:delete / reaction:toggle → 서버 확인·저장 → io.to(room:N).emit message:updated → 모두 교체
재연결:       connect 이벤트 → emit room:join → GET 메시지로 놓친 것 채우기 (id로 중복 제거)
```
